# bgm-animation-skill 🎬✏️

**给 AI 编程助手的视频技能**：丢一个参考视频 + 一句话，agent 自动提取 BGM、读歌词节奏、写分镜，用纯代码逐帧渲染一支踩点歌词的手绘风原创动画，合成 mp4 直接发短视频。

![demo](assets/demo.gif)

> 这条 demo 就是用本技能做的第一支成片：一首"抖音限流"主题歌 → 20.2 秒手绘小人动画（圈圈起手 / 限流印章 / 播放量卡在 9 / 落泪 / 做梦 / 星星收尾），606 帧全代码渲染，没有手绘一帧、没开剪辑软件。带声音的完整版看 [assets/demo.mp4](assets/demo.mp4)。

## 为什么是这个技能

市面上让 AI 做视频的路子无非两种：文生视频模型（不可控、烧积分）或者自己啃剪辑软件。这个技能走第三条路——**动画本来就是逐帧画出来的，而逐帧画图恰好是代码最擅长的事**：

- 节奏 100% 踩点（帧号=秒数×30，字幕窗口精确到帧）
- 手绘感靠算法：boiling line 抖动 + 起手画线演出（见下）
- 换一首歌 = 改一个时间线数组；换角色 = 改几个调色板变量
- 全流程零积分、零 API 费用、可复现

## 快速开始

1. 克隆本仓库
2. 把 **[SKILL.md](SKILL.md)** 发给你正在用的 AI 编程助手 —— **ZCode、Claude Code、Codex CLI、Cursor、iFlow…哪个都行**。本技能只依赖 Python，不绑定任何 agent 平台
3. 丢给它一个参考视频：「以这个视频的 BGM 做一支原创手绘动画」

agent 会自己完成：探测视频 → 无损提音轨 → RMS 找歌曲真实结束点 → 逐秒读参考片字幕建歌词时间轴 → 设计原创角色 → 逐帧渲染 → ffmpeg 合成 → 关键帧自查 → 交付 mp4。

## 环境要求

```bash
pip install pillow numpy imageio-ffmpeg
```

imageio-ffmpeg 自带 ffmpeg 静态二进制，**系统不用装 ffmpeg**。无 GPU、无外网依赖（除了 clone 这一步）。

## 手绘感从哪来

| 工艺 | 作用 |
|---|---|
| boiling line（每 2 帧换抖动种子） | 所有轮廓每帧微微"沸腾"，模拟逐帧手绘的呼吸感 |
| partial polyline（折线按长度截断） | 开场"画圆画线"的起手演出 |
| 2x 超采样 + LANCZOS | 线条抗锯齿 |
| 白底 + 纸感淡出 | 像画在纸上，不是浮在黑场 |
